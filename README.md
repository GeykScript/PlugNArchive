# PlugNArchive

**PlugNArchive** – The Automated Detection and Backup Tool for Memory Devices – is designed to streamline the management and backup of data from removable storage devices such as flash drives, SD cards, and external hard drives.

---

## 📥 Latest Version

To get the latest version:

1. Open the **Versions** folder.
2. Download the latest **executable file**.
3. Run the installer to install the application.

---

## 🛠 How to Use

1. **Insert** your flash drive or external storage device into the computer.  
2. **Run** the PlugNArchive application.  
3. **Select** the flash drive you want to back up.  
4. The **backup location** is already set, and you can view the path.  
5. **Choose** the type of files you want to back up:
   - Images
   - Videos
   - Music
   - Documents
6. **Click** **Create Backup**.  
7. **Done!** Your backup is complete.
8. **Eject Your Device.

---

## 📂 Additional Features

- **Archive History**: View all your past backups.  
- **About Us**: To download the latest version in the future, go to the **About Us** tab and click the link provided.

---

## ⚠ Notes

- Ensure your device is properly connected before running the application.  
- The backup location is predefined, but you can check or modify it if needed.
